useradd

Comando utilizado para crear nuevos usuarios en Linux.

sudo useradd -m -s /bin/bash luna
Argumento Descripción
-m Crea el directorio home del usuario.
-s Define la shell del usuario.
-G Agrega grupos secundarios.

Ver lista completa:

man useradd

usermod

Permite modificar propiedades de usuarios existentes.

sudo usermod -aG finanzas luna
Argumento Descripción
-aG Agregar usuario a grupos secundarios.
-l Cambiar nombre de usuario.
man usermod

groupadd

Crea grupos en Linux.

sudo groupadd developers
Argumento Descripción
-g Define manualmente el GID.
-r Crea grupo de sistema.
man groupadd

chmod

Modifica permisos de archivos y directorios.

chmod 2770 /home/shared/devs
Permiso Descripción
7 rwx
5 r-x
0 Sin permisos
man chmod

chown

Cambia propietario de archivos y carpetas.

sudo chown luna archivo.txt
man chown

chgrp

Cambia el grupo propietario de archivos y directorios.

sudo chgrp finanzas /home/shared/finanzas
man chgrp

ip

Herramienta moderna para administración de red.

ip a ip route
man ip

ping

Verifica conectividad de red.

ping 8.8.8.8
man ping

ss

Muestra conexiones y sockets activos.

ss -tunap
man ss

htop

Monitor interactivo de procesos y recursos.

htop
man htop

ps

Lista procesos activos.

ps aux
man ps

kill

Finaliza procesos por PID.

kill -9 20417
man kill

grep

Busca texto dentro de archivos.

grep root /etc/passwd
man grep

sed

Editor de streams y procesamiento de texto.

sed -n '5p' archivo.txt
man sed

awk

Herramienta poderosa para análisis de columnas y texto.

awk -F: '{print $1}' /etc/passwd
man awk

systemctl

Controla servicios en sistemas con systemd.

sudo systemctl status ssh
man systemctl

journalctl

Visualiza logs del sistema.

journalctl -xe
man journalctl

apt

Administrador de paquetes en Debian/Kali/Ubuntu.

sudo apt update sudo apt upgrade
man apt

passwd

Permite cambiar, bloquear y administrar contraseñas de usuarios.

sudo passwd luna sudo passwd -l luna sudo passwd -u luna
Argumento Descripción
-l Bloquea la contraseña del usuario.
-u Desbloquea el usuario.
-S Muestra estado del usuario.
man passwd

cp

Copia archivos y directorios.

cp archivo.txt backup.txt cp -r carpeta respaldo/ cp -p archivo.txt copia.txt
ArgumentoDescripción
-rCopiar directorios recursivamente.
-pPreservar permisos y fechas.
-vModo verbose.

mv

Mueve o renombra archivos y carpetas.

mv archivo.txt /home/shared/ mv viejo.txt nuevo.txt

ssh

Conexión remota segura a servidores Linux.

ssh usuario@192.168.1.10 ssh -p 2222 usuario@servidor
ArgumentoDescripción
-pPuerto personalizado.
-iUsar llave privada.

scp

Copia archivos entre sistemas usando SSH.

scp archivo.txt usuario@192.168.1.20:/home/usuario/ scp -r carpeta usuario@server:/backup/

sftp

Transferencia interactiva de archivos vía SSH.

sftp usuario@192.168.1.20 put archivo.txt get respaldo.zip

Pipes y Redirecciones

Permiten conectar comandos y redirigir salidas.

OperadorUso
|Enviar salida de un comando a otro.
>Sobrescribir archivo.
>>Agregar contenido al final.
2>Redirigir errores.
&Ejecutar en segundo plano.
ps aux | grep ssh ls > archivos.txt echo hola >> notas.txt find / 2> errores.txt comando 2> /dev/null htop &

find

Busca archivos y directorios.

find /home -name archivo.txt find /var -type d find / -perm 777

dpkg

Administrador de paquetes .deb en Debian/Kali/Ubuntu.

sudo dpkg -i paquete.deb dpkg -l dpkg --configure -a

zip

Comprimir y descomprimir archivos.

zip respaldo.zip archivo.txt zip -r backup.zip carpeta/ unzip backup.zip

kill y pkill

Finalización de procesos.

kill 20417 kill -9 20417 pkill firefox pkill -u luna
ArgumentoDescripción
-9Forzar terminación.
-uMatar procesos por usuario.

awk Avanzado

Uso avanzado con condiciones IF.

awk -F: '$3 >= 1000 {print $1, $3}' /etc/passwd

Interpretación:

$3 >= 1000 → UID mayor o igual a 1000 print $1 → mostrar usuario
ps aux | awk '$3 > 10 {print $1, $3, $11}'
